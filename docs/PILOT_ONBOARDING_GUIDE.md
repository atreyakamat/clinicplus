# ClinicOS Pilot Clinic Onboarding Guide

## Introduction
This guide provides the necessary steps to onboard your first pilot clinic onto ClinicOS.

## Pre-requisites
1.  **Organization Slug:** Choose a unique slug (e.g., `city-general`).
2.  **User List:** Names and emails of Doctors and Receptionists.
3.  **Branding Assets:** Clinic Logo (PNG/SVG) and Primary Hex Color.

## Step 1: Initial Setup
1.  Run the seeding script to create the basic organization and branch structure.
2.  Assign the `Organization Owner` role to the primary administrator.

## Step 2: User Training
### For Receptionists
- How to register new patients.
- How to book and manage appointments in the daily view.
- How to check-in patients and assign tokens.

### For Doctors
- How to use the Consultation Workspace.
- How to record vitals and clinical notes.
- How to generate and print prescriptions.

## Step 3: Data Migration
- Collect patient data in the standard CSV format.
- Use the **Patient Import** tool in the CRM module to bulk-upload records.

## Step 4: Branding Customization
- Navigate to **Settings > Branding**.
- Upload the logo and set the clinic's color scheme.
- Verify the appearance on a sample prescription print-out.

## Support
During the pilot, use the **Feedback** module within the app to report any issues or request urgent fixes.
