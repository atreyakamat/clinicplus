# Receptionist Testing Guide (UAT)

## Welcome to ClinicOS!
Please test the following critical flows:
1. Log in to the ClinicOS portal using Receptionist credentials.
2. Register a new Patient.
3. Schedule an Appointment for the new Patient.
4. Check-in the Patient to the Daily Queue.
5. Generate an Invoice for a completed Consultation.
6. Process a partial or full payment.
7. Submit feedback using the 'Report Issue' button.
