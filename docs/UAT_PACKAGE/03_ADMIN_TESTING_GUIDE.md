# Admin Testing Guide (UAT)

## Welcome to ClinicOS!
Please test the following critical flows:
1. Log in to the ClinicOS portal using Admin credentials.
2. Navigate to Organization Settings.
3. Add a new Branch or Department.
4. Invite a new Staff Member (Doctor/Receptionist).
5. Review the Analytics Dashboard.
6. Verify Audit Logs for recent staff actions.
7. Submit feedback using the 'Report Issue' button.
