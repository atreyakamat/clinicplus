# Doctor Testing Guide (UAT)

## Welcome to ClinicOS!
Please test the following critical flows:
1. Log in to the ClinicOS portal using your Doctor credentials.
2. View your Dashboard for today's Appointments.
3. Open a Patient file from the Queue.
4. Add Vitals and Chief Complaint.
5. Prescribe Medications.
6. Mark the Consultation as Completed.
7. Submit feedback using the 'Report Issue' button if you encounter errors.
